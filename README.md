# FrontierAtlas: Autonomous Intelligence Ingestion Engine

GraphOne / FrontierAtlas AI Engineer Assessment (Phases I - VI Compliant).

## Overview
Production-grade, fault-tolerant ingestion pipeline combining distributed web crawling, multi-tier LLM parsing, deterministic entity deduplication, and zero-hallucination data extraction.

## Deliverables Summary
- **Startups:** 1,000 verified startup records with valid source attribution.
- **Products:** 1,000 verified product records strictly adhering to pricing models (`FREE`, `FREEMIUM`, `PAID`, `ENTERPRISE`).
- **Research Papers:** 1,000 AI research papers with Arxiv URLs and dynamic GitHub star metrics.
- **Jobs:** High-fidelity AI job postings (< 24-hr fresh) from 5 distinct job boards.
- **News:** High-fidelity AI news signals (< 24-hr fresh) from 5 distinct news sources.
- **Entity Resolution Engine:** Deterministic deduplication using Jaro-Winkler, token-sort similarity, and canonical seed database.
- **Architecture Design:** 3-page production technical architecture specification (Phase VI).
